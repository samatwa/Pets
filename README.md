## Fjord FX

Install the dependencies in `Streamlit/Fjord-FX/requirements.txt`, then run:

```sh
streamlit run Streamlit/Fjord-FX/streamlit_app.py
```

For Streamlit Community Cloud, choose `Streamlit/Fjord-FX/streamlit_app.py` as the main file. Exchange-rate caches and local databases are generated when the app runs and are not included in this repository.
